 # ⚡ **PowerCalc UA: Онлайн-калькулятор автономного живлення під час блек-аутів**

> **Забудьте про складні формули та таблиці Excel!** Розрахуйте повні параметри вашої енергосистеми (від зарядного пристрою до сонячних панелей) всього за пару кліків.

---

### 🚀 **Основні можливості калькулятора:**

1. **🔌 Гнучкий підбір приладів та кастомного навантаження:**
* **Повний набір побутової техніки:** Холодильники, газові котли, циркуляційні насоси, роутери, освітлення, водопостачальні станції.
* **Високопотужні споживачі:** Вбудована підтримка **електроопалення** та **електроплит / варильних поверхонь** із можливістю вказати власну точну потужність (Вт).
 
2. **⏱ Адаптація під реальні графіки відключень світла:**
* **Час автономії:** Налаштовуйте тривалість блек-ауту (від 1 до 24 годин).
* **Вікно заряду:** Вказуйте реальну кількість годин, на яку вмикають електромережу, для точного розрахунку **потужності зарядного пристрою**.
 
3. **📊 Точний розрахунок за інженерними формулами:**
* **Потужність інвертора:** Враховує не лише сумарне споживання, а й **пускові струми (Surge Power)** для компресорів та насосів.
* **Ємність акумулятора (Вт·год та А·год):** Розрахунок здійснюється з урахуванням ККД інвертора ($\approx 88\%$), глибини розряду ($\text{DoD}$) та безпечного запасу ємності.
* **Автоматичний вибір напруги шини:** Калькулятор сам підкаже, яку напругу системи краще обрати — **12.8V, 25.6V чи 51.2V**, щоб уникнути перегріву кабелів.
 
4. **☀️ Розрахунок сонячної системи (PV & MPPT):**
* **Потужність сонячного масиву:** Розраховує необхідну сумарну потужність панелей та кількість блоків по 450 Вт.
* **Сезонність в Україні (PSH):** Можливість обрати пору року (Зима / Демісезон / Літо) для реалістичної оцінки генерації.
* **Параметри MPPT-контролера:** Визначення оптимального робочого струму заряду з урахуванням температурного запасу.
 
5. **🔋 Порівняльний інженерний аналіз хімії АКБ:**
* Наочне порівняння **LiFePO4** (літій-залізо-фосфат) та **Li-ion** (NMC) за швидкістю заряду, пожежну безпеку, ресурс циклів та вартість.
 
### 💡 **Чому це варто спробувати?**

* **Абсолютно безкоштовно та без реєстрації.**
* **Працює офлайн:** Завантажується однією сторінкою та працює навіть без доступу до інтернету.
* **Без помилок:** Запобігає купівлі слабкого інвертора або батареї, яка не встигне зарядитися за коротке вікно наявності світла.
